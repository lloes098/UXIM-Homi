# Homi

> 2차 제비뽑기로 시작하는 매물 탐방,,, 테스트 수정 중 ,계약,,,,  
> 청년·대학생을 위한 모바일 주거 내비게이션 서비스

## Overview

Homi는 첫 자취와 첫 임대차 계약을 앞둔 청년·대학생이 더 안전하고 확신 있게 매물을 탐방할 수 있도록 돕는 주거 탐색 지원 서비스입니다.

청년 주거 탐색 과정은 단순히 좋은 매물을 찾는 문제가 아니라, 정보의 신뢰도, 현장 방문의 불안감, 계약 판단의 어려움이 복합적으로 얽힌 경험입니다. Homi는 이 과정에서 사용자가 혼자 판단해야 하는 부담을 줄이고, 동행 매칭과 현장 점검 체크리스트를 통해 매물 탐방의 심리적·실질적 안전성을 높이는 것을 목표로 합니다.

## Problem

청년과 대학생은 기숙사 수용률 부족, 높은 월세 부담, 부동산 거래 경험 부족으로 인해 생애 첫 주거 계약에서 큰 불안을 경험합니다.

기존 부동산 플랫폼은 매물 탐색과 정보 확인에는 강점을 가지지만, 다음과 같은 한계가 있습니다.

- 허위·과장 매물 여부를 사용자가 직접 판단해야 함
- 현장 방문 시 소음, 냄새, 채광, 안전 등 실제 환경을 혼자 점검해야 함
- 계약 전 확인해야 할 항목이 많지만 초보 임차인이 기준을 알기 어려움
- 혼자 매물을 보러 가는 과정에서 심리적 불안감이 발생함

Homi는 사용자의 핵심 페인포인트가 단순한 정보 부족이 아니라 `판단의 불안`이라는 점에 주목했습니다.

## Solution

Homi는 매물 탐방 과정에서 사용자가 믿을 수 있는 동행인을 연결하고, 체크리스트 기반으로 현장을 점검할 수 있도록 돕습니다.

기존에는 3D 원격 뷰잉과 기술 중심 탐색을 주요 기능으로 검토했으나, 사용자 리서치 결과 실제 사용자는 비대면 기술보다 심리적 안정감을 주는 동행 지원을 더 필요로 한다는 인사이트를 얻었습니다.

이에 따라 서비스 방향을 `기술 중심 탐색`에서 `사람 중심 동행 지원`으로 전환했습니다.

## Key Features

### 1. 동행 구하기

매물 탐방을 혼자 진행하기 어려운 사용자가 신뢰 가능한 동행인을 찾을 수 있습니다.

- 동행 요청 등록
- 희망 지역 및 시간 입력
- 동행 유형 선택
- 매물 탐방 목적 공유

### 2. 매물 탐색

사용자는 관심 매물을 확인하고, 탐방 전 필요한 정보를 정리할 수 있습니다.

- 매물 정보 확인
- 탐방 예정 매물 관리
- 3D 뷰잉 또는 매물 미리보기 보조 기능
- 매물별 비교 및 탐색 흐름 지원

### 3. 현장 점검 체크리스트

초보 임차인이 놓치기 쉬운 현장 확인 항목을 체크리스트로 제공합니다.

- 채광, 소음, 냄새, 수압, 하자 여부 점검
- 체크리스트 진행률 확인
- 현장 기록 저장
- 계약 전 판단 보조

### 4. 신뢰 기반 매칭 구조

동행 서비스의 안전성을 높이기 위해 신뢰 장치를 설계합니다.

- 신원 인증
- 평점 시스템
- 안전 매칭 구조
- 결제 및 확정 절차

## User Research

Homi는 신촌권 대학생 및 사회초년생을 대상으로 설문조사와 심층 인터뷰를 진행했습니다.

리서치를 통해 다음과 같은 핵심 인사이트를 도출했습니다.

- 사용자는 원격 3D 뷰잉보다 실제 현장 방문의 심리적 안정감을 더 중요하게 여김
- 매물 탐색 과정의 핵심 문제는 정보 부족보다 판단 불안에 가까움
- 동행인은 단순 보조자가 아니라 사용자의 불안을 줄이는 신뢰 장치로 기능함
- 체크리스트는 초보 임차인의 판단 기준을 보완하는 핵심 도구가 될 수 있음

## Target Users

- 첫 자취를 준비하는 대학생
- 신촌권 또는 대학가 주변에서 방을 구하는 청년
- 부동산 계약 경험이 부족한 사회초년생
- 혼자 매물을 보러 가는 것이 불안한 사용자
- 현장 방문 시 무엇을 확인해야 할지 모르는 사용자

## Service Goal

Homi의 목표는 청년 주거 탐색의 시간, 비용, 심리적 위험을 줄이는 것입니다.

사용자가 매물을 단순히 빠르게 찾는 데서 그치지 않고, 스스로 더 안전한 선택을 내릴 수 있도록 돕는 주거 탐색 경험을 제공합니다.
